# Verificación

Skill disponible al modelo, sin comando de workflow. Parte del objetivo/acceptance: identifica truths esperadas, artefactos, wiring y resultado observable; prueba rutas integradas cuando el cambio lo requiera. Consulta `sol-engineering-practices/references/testing.md` solo si ayuda a elegir pruebas. Comprueba estado/frescura después de la última edición relevante. Informa por criterio passed/failed/not run/no disponible con comando/observación y límites. No marques requerido PASS si no se ejecutó o carece de evidencia positiva; no confundas test, resumen o recibo con aceptación integral. Las brechas llevan a reparación focalizada, no a reiniciar todo el proceso.
