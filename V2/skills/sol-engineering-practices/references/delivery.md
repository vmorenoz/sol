# Alcance Git y entrega

Durante trabajo local, inspecciona solo el estado necesario para separar cambios propios y ajenos; no asumas autoría por branch/HEAD ni incluyas archivos ajenos. Revisa el diff contra el scope. No hagas commits por corte, push, PR, merge, tag, release, deploy, stash o `git add -A` sin autorización específica.

Si la entrega externa se solicita, `sol-ship` y su preflight/intent/autorización nativos son la única guía operativa. Presenta snapshot, paths, destino y acciones; permiso del host y consentimiento del usuario son controles distintos. No ejecutes Git por shell siguiendo recetas upstream ni dupliques el flujo de Ship.
